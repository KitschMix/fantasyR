🎨 Stitch 디자인 통합

Google Stitch로 게임 UI 디자인하기

🎮 게임 선택

📖 워크플로우

  1. Stitch 열기 버튼 클릭 → Stitch UI가 iframe으로 로드됨
  2. Stitch에서 UI 디자인 (예: "스플렌더 점수판")
  3. 디자인 가져오기 → Stitch에서 export한 .zip 파일 선택
  4. 가져온 HTML/CSS가 우리 게임 페이지에 통합됨
  5. Stitch로 보내기 → 우리 기존 페이지를 Stitch에 보내 디자인 개선
